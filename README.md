# TermoSafe – Sistema integrado de produção, estoque e logística com monitoramento da cadeia fria

Projeto extensionista da disciplina **Desenvolvimento de Software** – Universidade Presbiteriana Mackenzie, Faculdade de Computação e Informática.

## Resumo

O TermoSafe é uma proposta de sistema para indústrias farmacêuticas que fabricam **medicamentos termolábeis** (vacinas, insulinas e biológicos). Ele integra os módulos de **Gestão de Produção** e **Gestão de Estoque e Logística** a um módulo de **monitoramento térmico**, de modo que a temperatura faça parte da história de cada lote: do recebimento do insumo à entrega ao destinatário. Quando um sensor detecta uma excursão de temperatura, o sistema bloqueia automaticamente os lotes afetados e exige a avaliação do responsável técnico.

O projeto contempla levantamento de requisitos, modelagem UML, proposta de arquitetura e justificativa da integração entre os módulos. Não há implementação de código.
